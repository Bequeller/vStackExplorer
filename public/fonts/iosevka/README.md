## Provenance (temporary)

These files are Iosevka v22.1.2 (latin subset), taken unchanged from the npm package
`@fontsource/iosevka@5.3.0` (`files/iosevka-latin-400-normal.woff2` and
`files/iosevka-latin-700-normal.woff2`), which redistributes the upstream release under the OFL.
`LICENSE.md` is the license file shipped in that package.

They are a stand-in: the build session could not download the official release asset
(`PkgWebFont-Iosevka-34.9.1.zip`, 259 MB, from https://github.com/be5invis/Iosevka/releases/tag/v34.9.1)
because of the session's network policy. See `docs/decisions/0006-iosevka-font-source.md`.

To replace them: download that zip, take the Regular and Bold upright `.woff2` files,
save them under the same names here, copy the release's `LICENSE.md`, and update the table above.
